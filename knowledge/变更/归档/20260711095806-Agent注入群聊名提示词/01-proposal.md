## 变更说明

在发给 agent 的提示词/上下文**最前面**插入一行 `group_name: <当前群聊名>`（仅首行插入即可）。无群名时降级为最简处理：写入空串，或省略该行。

## 验收标准

1. 有群聊名时，组装后的 agent 提示词/上下文**首行**为 `group_name: <当前群聊名>`，其后为原有内容。
2. 无群聊名时，不注入无效占位：要么省略该行，要么首行为 `group_name: `（空串），行为与实现约定一致且可预期。
3. 仅影响提示词组装，不改变 agent 执行引擎、会话隔离、IM 发送协议或其他通道契约。

## 影响范围

- **端**：单端 Electron（主进程 agent 提示词/上下文组装路径）
- **范围**：提示词首行注入；不改 proto、数据库、权限、跨端接口
- **知识库**：知识同步型 lite，实现后按需更新对应工程平台/业务域中「agent 提示词组装」相关说明（本阶段仅落盘变更文档，不改业务域正文）
