## 背景

多会话与长任务并存时，用户侧体感仍有明显缺口：

1. **同目录第二会话**：仅有日志 WARN，通道侧提示不足，用户不易察觉冲突风险。
2. **飞书长任务中途像死机**：长静默无进度心跳 / CardKit 续期，易误判卡住。
3. **空闲刷新仅发前**：≥15min 空闲后刷新/重建偏「发消息前」触发，后台预热与多会话节流不足。
4. **tool 阶段不可见**：`tool_running` 缺少「正在执行」与超时可操作提示，长时间工具调用无反馈。
5. **入队静默**：同会话后续消息入队后缺少明确「已排队」文案，不符合三态文案规矩。

本变更在不引入假 SDK turn、不默认硬阻断同目录第二会话的前提下，补齐上述体验闭环。

## 变更说明

| 任务 | 要点 |
|------|------|
| LITE-01 | 长静默时飞书侧进度心跳 / CardKit 续期；**禁止**伪造 SDK turn |
| LITE-02 | 空闲 ≥15min 后台预热 `recreate`；多会话场景节流，避免雪崩 |
| LITE-03 | 同 `workspaceDir` 第二会话：通道可见提示；**不默认硬阻断** |
| LITE-04 | `tool_running` 展示「正在执行」并刷新；卡住超 N 分钟提示 `/stop` `/status` |
| LITE-05 | 同会话入队给出明确「已排队」体感文案，符合三态文案规矩 |

## 验收标准

1. **LITE-01**：长静默期间飞书侧有进度/CardKit 续期；全程无假 SDK turn。
2. **LITE-02**：空闲 ≥15min 触发后台预热 recreate；多会话并发时有节流，不致同时风暴 recreate。
3. **LITE-03**：同 `workspaceDir` 开第二会话时，通道有可见提示；默认不硬阻断。
4. **LITE-04**：`tool_running` 展示正在执行的工具并刷新；超 N 分钟给出可操作提示（如 `/stop` `/status`）。
5. **LITE-05**：同会话入队有明确「已排队」文案，且符合排队三态文案规矩。
