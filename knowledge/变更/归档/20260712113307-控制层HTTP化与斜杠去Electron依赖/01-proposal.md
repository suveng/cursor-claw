# 控制层HTTP化与斜杠去Electron依赖产品需求文档

> **变更 ID**：`20260712113307-控制层HTTP化与斜杠去Electron依赖`
> **来源**：kb-propose
> **类型**：建议「技术债 / 可靠性」（待闸门确认）
> **优先级**：建议 P1（待闸门确认）
> **外部 PRD**：无
> **Figma 设计图**：无
> **任务记录**：无

## 一、背景与问题

产品债 **T10**：`/mcp` 等管理能力仍经 admin MCP；斜杠指令依赖 Electron claim 本地命令队列。Daemon 已是 IM 编排 SSOT，控制面却分裂，导致 Daemon 单独运行或 Electron 未就绪时斜杠不可靠，远程调用须绕道桌面进程。

## 二、用户可见症状

- `/status`、`/help` 等偶发无响应，依赖 Electron 轮询
- `/mcp` 管理不走统一 HTTP
- Electron 重启期间斜杠丢失或延迟
- 用户难判断应找 Daemon 还是桌面端

## 三、目标与非目标

**目标**：斜杠改由 Daemon HTTP 受理；`/mcp` 类管理走 Daemon HTTP；授权与结果语义与现网一致；与 T8 可后半并行但须划界。

**非目标**：不改卡片视觉、引擎 SDK、全量废除 MCP、不改微信。

## 四、用户与场景

日常斜杠；MCP 配置管理；Electron 重启期间斜杠仍可用；与 `/merge` 共用控制面；迁移期保留必要降级。

## 五、功能需求

| 编号 | 需求 |
|------|------|
| R1 | 斜杠主路径由 Daemon HTTP 执行 |
| R2 | `/mcp` 类管理提供 HTTP 等价入口 |
| R3 | 授权、节流、多会话路由与现网一致 |
| R4 | Electron 本地队列降为兼容或移除，边界文档化 |
| R5 | 与 T8 明确 API 契约后再扩展 |

## 六、验收标准

1. 主路径斜杠在 Electron 未 claim 时仍可完成
2. `/mcp` 核心动作经 Daemon HTTP 可比现网
3. Electron 重启窗口内斜杠不静默丢失
4. 未授权仍被拒绝且提示可理解
5. 卡片与 Agent 执行无回归

## 七、范围边界

**在范围**：Daemon HTTP 控制层、斜杠去 Electron 依赖、admin MCP 控制类迁移。**不在范围**：UI、SDK、file-queue、微信。

## 八、风险与依赖

- **依赖 T8** 之后或划界后并行
- **双写期** 防重复执行
- **授权 SSOT** 须 HTTP 与旧路径一致

## 九、知识库影响初评

Daemon 概览 T10（高）；HTTP 与 MCP 服务（高）；飞书通道斜杠（中）。
