**前置**：Electron 已启动；飞书通道已绑定 `larkAppId`（`cli_` 前缀）；飞书客户端可扫码。

| 场景 ID | 步骤 | 期望 |

### 4.3 飞书私聊菜单

**前置**：权限/事件已扫码补齐；飞书后台已配置私聊自定义菜单（对照 Settings event_key 表）；Daemon 已连接。

| 场景 ID | 步骤 | 期望 |
|---------|------|------|
| **F1** 基础菜单可见 | 普通用户打开私聊 | 输入框旁见基础分组（01·1） |
| **F2** 状态 | 点「查看状态」 | 与 `/status` 一致（01·2） |
| **F3** 停止 | 点「停止」 | 与 `/stop` 一致（01·3） |

| **F5** 管理员项 | 管理员私聊点工作区/模型/新建会话 | 与对应斜杠一致（01·5、7） |
| **F6** 无权限 | 非管理员点管理员项（若可见） | 「🔒 该指令仅管理员可用」；无管理员副作用（01·6） |
| **F8** 推送事件 | 至少一项配置为推送事件 | 点击后执行指令非仅发字（01·8） |

| **F10** 进入帮助卡 | 首次进入私聊（或超 24h） | 收到帮助 CardKit（01·10） |
| **F11** 文案一致 | 对照帮助卡、`/help`、菜单名 | 无矛盾（01·11） |
| **F12** 节流 | 24h 内再次进入私聊 | 不重复发卡（01·12） |
