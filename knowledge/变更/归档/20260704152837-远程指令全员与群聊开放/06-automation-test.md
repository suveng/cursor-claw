## 4、场景摘要

### 4.1 静态检查

| 检查项 | 操作 | 期望 |
|--------|------|------|
| TypeScript | `npx tsc --noEmit` | exit 0 |
| admin 门控残留 | `rg` src/electron 无 `denyNonAdmin`/`adminOnly`/`该指令仅管理员` | 无匹配 |

| Review | R1 fixed；D1/D2 debt | 04-review §9 通过 |

### 4.2 飞书私聊（非主用户）

**前置**：通道 `allowOthers` 已开；非主用户已与机器人私聊；Daemon 已连接；飞书后台菜单已配 `cmd_*`（若测菜单）。

| 场景 ID | 步骤 | 期望 |
|---------|------|------|
| **P1** 文本斜杠 | 发 `/workspace`、`/model`、`/list` | 成功或业务错误；**不得**「仅管理员」 |
| **P2** 菜单 | 点 `cmd_workspace` / `cmd_chat_new` | 与文本路径结果一致 |
| **P3** 帮助 | `/help`；重新进入私聊（>24h 或清节流） | 全文含管理类指令；无「管理员」标题 |

### 4.3 飞书群聊

**前置**：用户可 @ 机器人对话（群 + 通道配置允许）。

| 场景 ID | 步骤 | 期望 |
|---------|------|------|
| **G1** 群聊斜杠 | @ 后发 `/workspace`、`/chat new` | 与私聊一致，非角色拒绝 |

### 4.4 边界与其它

| 场景 ID | 步骤 | 期望 |
|---------|------|------|
| **S1** `/stop` | 会话有 Agent 时发 `/stop` | 仅停当前会话；主用户 p2p 亦不停全局 Agent |
| **B1** 通道未授权 | `allowOthers` 关时他人私聊 | 无法对话或通道级提示，非斜杠 admin 文案 |
| **W1** 微信 | 非主用户微信发 `/status`、`/workspace` | 与飞书同规则（02·R3） |
| **R1** 回归 | `/status` `/reset` `/help` | 仍可用 |
