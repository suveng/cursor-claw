# 配置与更新

## 一、能力范围

配置持久化（`config-store.ts`）、开机自启、关闭行为、代理、Daemon 端口、崩溃分析目录；托盘；应用内更新；工作区注入（已废弃自动写盘）。

## 二、设计决策与取舍

- electron-store（`cursor-claw-config`）+ encryptionKey。
- 自动 inject 为 no-op；launch/Daemon 就绪不得写 `~/.cursor` rules/MCP。
- `workspace:inject` 仅写项目 admin Skill；可选手动 `cleanupLegacyInjection`。
- 更新：macOS Homebrew；Windows electron-updater。
- **updater**：入口 `updater.ts`（`initAppUpdater`/`registerUpdaterIpc`/`fetchLatestRelease`）；实现 `updater-types`/`modal`/`release`/`apply`（均 ≤300）；域外仍 import 入口。

## 三、服务端规则

无。Daemon 端口默认 19528（`LARK_DAEMON_PORT`）。

## 四、客户端流程

### MCP 手动配置

不自动写 Cursor `mcp.json`。Settings MCP Tab 顶 `SettingsMcpDaemonGuide`：可复制 `cursor-claw`→`http://127.0.0.1:{daemonPort}/mcp`。开关/健康经 IM `/mcp` 或 `POST /api/mcp`。

### 多引擎 Settings MCP

| 引擎 | Settings | 落盘 |
|---|---|---|
| sdk | CRUD | `~/.cursor/mcp.json`、项目 `.cursor/mcp.json` |
| claude-code | 只读 | `~/.claude.json`、项目 `.mcp.json` |
| codex | 只读（无 TOML 编辑） | `~/.codex/config.toml` 等 |
| opencode | 只读 | `opencode.json` 等 |

只读经 `agent:mcp-status` 无 session 读盘。

### 工作区注入

launch/就绪不写盘；`workspace:inject`→admin Skill；`cursor-claw.mdc` 为 Legacy。见 [Agent调度/03-启动与自动重连](../../业务域/Agent调度/03-启动与自动重连.md)。

### 崩溃分析与 Profile 日志

- `SettingsGeneralTab`：`crashAnalysisDir` autoSave；空=跳过归档。
- Profile `daemonLogPath`；`resolveActiveDaemonLogPath`→启用通道 Profile / `{workspaceDir}/.cursor/daemon.log` / `{userData}/logs/daemon.log`；注入 `DAEMON_LOG_PATH`。

### 更新

启动 4s `runStartupUpdateCheck`；changelog→`updater-release`；brew/win→`updater-apply`。

## 五、接口

| IPC | 说明 |
|---|---|
| `config:get/save` | AppConfig |
| `workspace:inject` | 仅 admin Skill |
| `updater:check/apply/current-version` | 更新 |

关键字段：`workspaceDir`、`crashAnalysisDir`、`daemonLogPath`、`daemonPort`、`setupComplete`、`cliMigrationPending`。

`AgentResource.type`：sdk/claude-code/codex/opencode；无虚拟 cli。启动 `migrateCliBindings` 清历史 cli。

## 六、数据

userData；profile 子目录 `cursor-claw-{profile}/`。

## 八、推送

`updater:status` / `updater:error`。
