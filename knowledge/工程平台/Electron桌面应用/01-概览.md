# Electron 桌面应用 · 概览

## 一、模块定位与边界

Cursor Claw 桌面端：可视化配置、spawn Daemon、MCP/Rules/Skills 管理，IPC 驱动 React UI。消息桥接与 MCP HTTP 由 Daemon 承担。

## 五、关键约束

- 渲染进程 `contextIsolation: true`，仅 `window.electronAPI`。
- `--profile=xxx` 隔离 userData。
- Daemon 仅 `127.0.0.1`；默认端口 19528。
- Claude Agent：`claude-agent-sdk-*` optional dep；asarUnpack 解包二进制。

## 八、全局非功能与可观测

- 主进程未捕获异常写入 UI 日志；Daemon stdout 特殊前缀由 daemon-manager 解析广播。
- Daemon 60s 内异常退出最多自动重启 5 次。
- **双引擎 watchdog 超时 IM 对称**：CC（`finalizeCcRunOnWatchdogTimeout`）与 SDK（`finalizeSdkRunOnTimeout`）空闲/绝对超时后各发一条 `formatUserSdkFailureMessage({ isTimeoutFailure: true })` 文案 + `stop_progress`，phase→idle；**不写** cooldown map，同会话可续跑。
- **CC 活动时钟**：`buildQueryOptions` 注入 `hooks`（SubagentStart/PreToolUse/PostToolUse）与 `includeHookEvents: true`；回调与 `hook_*` 流事件经 `markSessionActivity` 刷新 `lastActivityAt`（默认空闲 300_000ms，`CC_IDLE_TIMEOUT_MS`）。
- **CC hook 可观测**：UI 日志含 `hook_event=`（回调可含 `agent_type=`/`tool_name=`）；禁止 hook 原文 IM notify。
