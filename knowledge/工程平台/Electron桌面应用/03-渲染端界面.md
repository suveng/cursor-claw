# 渲染端界面

## 一、能力范围

React+Tailwind：`App.tsx` 路由 Dashboard/Settings；含 `SettingsEngineShell`、`SettingsRulesPanel`、`SettingsMcpEngineBlock`。经 `window.electronAPI` 通信。

## 二、设计决策与取舍

- **双页 hide 切换**：保留 Settings 状态。
- **Dashboard**：`Dashboard.tsx` 为组装壳（签名 `Dashboard({ onSettings, active })`）；引导 / 状态卡 / 详情 / 日志分别在 `DashboardOnboard`、`DashboardStatusCards`、`DashboardDetailPanels`、`DashboardLogPanel`（均 ≤300）。
- **Settings 11 Tab**：通用/网络/Agent/消息通道/Rules/Skills/定时任务/MCP/工作流/帮助引导/关于。`Settings.tsx` 为 Tab 壳 + 共享 load；内联 Tab 迁至 `SettingsGeneralTab` / `Proxy` / `Tasks` / `Setup` / `About`（pages/，均 ≤300）。
- **通道面板**：`ChannelPanel.tsx` 列表壳；编辑弹窗 `ChannelEditModal` + `ChannelEditWechat` / `ChannelEditAccess`；辅助 `channel-panel-helpers.ts`（`emptyChannel` 等）。
- **微信文案落点**：群模式/显示名说明在 `ChannelEditWechat`；主次通道能力对照在 `SettingsSetupTab`（与消息桥接概览 §九 同口径，无新布局）。
- **引擎分块**：Rules/Skills/MCP 共用 `SettingsEngineShell`，按 `deriveBoundEngineTypes`；标签 SSOT `RESOURCE_GROUP_LABELS`。
- **Rules/Skills 仅 SDK**：`sdk ∈ boundTypes` 才渲染；无 SDK 时专属引导。
- **MCP**：Tab 顶 `SettingsMcpDaemonGuide`；引擎块 `SettingsMcpEngineBlock`；Dashboard `SessionMcpPanel` 会话诊断。
- **自动保存**：general/setup 500ms debounce。

## 三、服务端规则

无；通道/ws 校验在 main 才允许 startDaemon。

## 四、客户端流程

general：`workspaceDir`/`crashAnalysisDir` autoSave（`SettingsGeneralTab`）。Agent Tab 各 Profile 经 `ProfileDaemonLogField` 可配 `daemonLogPath`。引导：工作目录→Agent（四引擎 Profile）→通道→启 Daemon。`ChannelModelSection` 用 `RESOURCE_GROUP_LABELS` 分组。

Settings Rules/Skills/MCP：`SettingsEngineShell`+`deriveBoundEngineTypes`；加载前不空态闪烁。MCP Tab：可复制 `cursor-claw`→`http://127.0.0.1:{daemonPort}/mcp`；`SettingsMcpEngineBlock`：sdk CRUD；`claude-code`/`codex`/`opencode` 只读读盘。

Dashboard：Daemon/通道/队列/Agent/日志；会话展开 `SessionMcpPanel`；disk 空态「未探测」（`formatMcpPanelStatusLabel` SSOT：`mcp-health-label.ts`）。

## 五、接口

| UI | API |
|---|---|
| Daemon | `startDaemon`/`stopDaemon` |
| 会话 MCP | `getAgentMcpStatus`/`getMcpTools`/`loginMcp` |
| Settings MCP | `SettingsMcpDaemonGuide`；SDK `mcp:*`；只读 `getAgentMcpStatus` |
| Rules | `getRules`/`saveRule`/`deleteRule` |
| 模型 | `listSdkModels`/`listCcModels` |

## 六、数据

React state + `saveConfig`；`deriveBoundEngineTypes`/`RESOURCE_GROUP_LABELS` 在 `channel-types.ts`。

## 七、非功能与可观测

日志 300 行；`UpdateDownloadBanner`/`AppModalHost`；IPC `onDaemonStatus`/`onSessionAgents` 等。壳与子组件均 ≤300 行。

## 八、推送

无独立推送层；见 §七 IPC 订阅。
