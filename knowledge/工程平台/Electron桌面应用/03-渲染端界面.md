# 渲染端界面

## 一、能力范围

React+Tailwind 渲染层：`App.tsx` 路由 Dashboard/Settings；组件含 TitleBar 等。经 `window.electronAPI` 通信。

## 二、设计决策与取舍

- **双页 hide 切换**：CSS `hidden` 保留 Settings 状态。
- **Dashboard 三步引导**：工作目录→Agent 资源→消息通道。
- **Settings 10 Tab**：通用/网络/Agent/消息通道/Rules/Skills/定时任务/工作流/帮助引导/关于（无 MCP Tab）。
- **MCP 诊断在 Dashboard**：`SessionMcpPanel` 按 `engineType` dispatch 取数；emptyHint 区分 CC/SDK 配置源。
- **自动保存**：general/setup 500ms debounce 写 config。

## 三、服务端规则

无；配置校验在 main（通道/ws 必填）才允许 startDaemon。

## 四、客户端流程

### Settings general Tab

主工作目录（`workspaceDir`）与崩溃分析目录（`crashAnalysisDir`）：目录选择器 + autoSave；留空跳过归档（见 02 §七）。

### 初始化引导（Dashboard）

1. 选主工作目录→`general` 2. 配 Agent 资源（SDK Key/CC Profile）→`agent` 3. 加飞书/微信通道并绑定→`channel` 4. 启动 Daemon。CLI 用户见迁移 Banner（`cliMigrationPending`）；帮助引导 Tab 列同三步与飞书权限 JSON。

通道编辑 `ChannelModelSection`：CC Profile 模型在 Profile 层，Cursor 保留通道级模型。

### Dashboard 功能区

Daemon 启停、通道/队列/活跃 Agent、实时日志；AgentPanel 仅 SDK/CC 资源管理（无 CLI 入口）。

### Dashboard 活跃会话与 MCP

会话行可展开；上方 `SessionMcpPanel`（入参 `sessionKey`/`ws?`/`engineType`/`fallbackWs`），下方排队消息。只读列表/状态/刷新/OAuth/工具折叠，无 CRUD。

`loadMcp(force)` 按 `engineType` dispatch：CC/SDK 调 `getAgentMcpStatus(sessionKey, force, engineType, effectiveWs)`；codex `viewConfig.supported=false` early return，不直调 `listMcpForWorkspace`/`getMcpStatusMap`。`engineType` 为 `McpEngineType="sdk"|"claude-code"|"codex"`（`mcp-view-strategy.getMcpViewConfig`）。`effectiveWs`：会话 ws 优先、空回退 `fallbackWorkspaceDir`，仅用于 `getMcpTools`/`loginMcp`/`emptyHint`。emptyHint：CC 指 `~/.claude.json`+`{ws}/.mcp.json`（不含 `.cursor`）；SDK 指 `.cursor/mcp.json`；codex 占位。类型 `McpServerEntry`/`AgentMcpStatusResult` 在 `types/mcp.d.ts`（ambient）；UI 识别 `ready/enabled/disabled/needs_login`，经 `mapCcStatusToUi` 映射。

## 五、接口

渲染层仅调 preload Promise API，无直接 HTTP。关键调用：

| UI 动作 | API |
|---|---|
| 启停 Daemon | `startDaemon`/`stopDaemon` |
| 通道绑定 | `startChannelBind`/`onBindResult` |
| 活跃会话列表 | `getSessionAgents`/`onSessionAgents`（含 `ws?`、`engineType`） |
| 会话 MCP 诊断 | `getAgentMcpStatus(sessionKey, force, engineType, effectiveWs)`（CC/SDK）；`getMcpTools`/`loginMcp`（工具/OAuth）；`listMcpForWorkspace`/`getMcpStatusMap` 不直调 |
| 模型列表 | `listSdkModels`/`listCcModels`（无 `models:list`） |
| 更新 | `checkAppUpdate`/`applyAppUpdate` |

## 六、数据

UI 状态本地 React state；持久化经 `saveConfig` 写 electron-store。

## 七、非功能与可观测

- 日志面板保留最近 300 行；`UpdateDownloadBanner` 监听 `onUpdaterStatus/Progress`；`AppModalHost` 渲染 `app:modal-request`。

## 八、推送
