# 渲染端界面

## 一、能力范围

React+Tailwind：`App.tsx` 路由 Dashboard/Settings；含 `SettingsEngineShell`、`SettingsRulesPanel`、`SettingsMcpEngineBlock`。经 `window.electronAPI` 通信。

## 二、设计决策与取舍

- **双页 hide 切换**：保留 Settings 状态。
- **Dashboard 引导**：工作目录→四引擎 Agent 资源→消息通道；`agentReady` 含 sdk/claude-code/codex/opencode 有效 apiKey。
- **Settings 11 Tab**：通用/网络/Agent/消息通道/Rules/Skills/定时任务/MCP/工作流/帮助引导/关于。
- **引擎分块**：Rules/Skills/MCP 共用 `SettingsEngineShell`，按 `deriveBoundEngineTypes(channels, agentResources)`；标签 SSOT `RESOURCE_GROUP_LABELS`（`channel-types.ts`）。
- **Rules/Skills 仅 SDK**：`sdk ∈ boundTypes` 才渲染面板；无 SDK 时专属引导（`allBoundTypes` 区分绑定失效）。
- **MCP**：Settings MCP Tab 顶部 `SettingsMcpDaemonGuide` 可复制 Cursor→Daemon 片段；引擎块经 `SettingsMcpEngineBlock`（SDK CRUD / CC·Codex·OpenCode 只读读盘）；Dashboard `SessionMcpPanel` 会话诊断。
- **自动保存**：general/setup 500ms debounce。

## 三、服务端规则

无；通道/ws 校验在 main 才允许 startDaemon。

## 四、客户端流程

general：`workspaceDir`/`crashAnalysisDir` autoSave。Agent Tab 各 Profile 编辑弹窗经 `ProfileDaemonLogField` 可配 `daemonLogPath`（留空默认）。引导：工作目录→Agent（四引擎 Profile）→通道→启 Daemon。`ChannelModelSection` 用 `RESOURCE_GROUP_LABELS` 分组。

Settings Rules/Skills/MCP：`SettingsEngineShell`+`deriveBoundEngineTypes`；加载前不空态闪烁。Rules/Skills 仅 sdk→`SettingsRulesPanel`。MCP Tab：`SettingsMcpDaemonGuide` 一键复制 `cursor-claw`→`http://127.0.0.1:{daemonPort}/mcp` 片段（与 `buildMcpServers` 一致，脚注指向 IM `/mcp` 或 `POST /api/mcp`）。`SettingsMcpEngineBlock`：sdk→`SettingsMcpSdkSection` CRUD；`claude-code`/`codex`/`opencode`→`SettingsMcpDiskReadonly` 经 `getAgentMcpStatus("",…,engineType,ws)` 无 session 读盘，展示路径头与空态引导（Codex 标明设置页不提供 TOML 编辑）。

Dashboard：Daemon/通道/队列/Agent/日志；Agent Tab 四引擎。会话展开 `SessionMcpPanel` 只读；四引擎均经 `getAgentMcpStatus`；disk 来源空 `statusMap` 标「未探测」（`formatMcpPanelStatusLabel` SSOT：`src/shared/mcp-health-label.ts`）。

## 五、接口

| UI | API |
|---|---|
| Daemon | `startDaemon`/`stopDaemon` |
| 会话 MCP | `getAgentMcpStatus`/`getMcpTools`/`loginMcp` |
| Settings MCP | Tab 顶 `SettingsMcpDaemonGuide`；SDK `mcp:*` CRUD；CC/Codex/OpenCode 只读 `getAgentMcpStatus("",…,engineType,ws)` |
| Rules | `getRules`/`saveRule`/`deleteRule` |
| 模型 | `listSdkModels`/`listCcModels` |

## 六、数据

React state + `saveConfig`；`deriveBoundEngineTypes`/`RESOURCE_GROUP_LABELS` 在 `channel-types.ts`。

## 七、非功能与可观测

日志 300 行；`UpdateDownloadBanner`/`AppModalHost`；IPC `onDaemonStatus`/`onSessionAgents` 等。

## 八、推送

无独立推送层；见 §七 IPC 订阅。

## 九、已知限制与 TODO
