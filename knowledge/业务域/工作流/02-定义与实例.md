# 工作流 · 定义与实例

## 一、能力范围

蓝图（WorkflowDefinition）与实例（WorkflowInstance）模型、YAML/JSON 解析、磁盘持久化、内置种子。不负责引擎流转。

## 二、设计决策与取舍

- 每定义一文件 `definitions/{id}.yaml`；旧 `definitions.json` 启动迁移（`workflow-definition-store.ts`）。
- 有序节点链，无专用 review 类型；产物格式由 prompt 约定。
- **存储 SSOT**：`workflow-path.ts` 懒解析 `{APP_DATA_DIR}/workflows`；Daemon 与 Electron 共用（Electron `workflow-file.ts` 设 `APP_DATA_DIR=userData` 后委托 `workflow-store`）。
- 遗留双目录：SSOT 空且 legacy 有 `instances/*.json` 时一次性复制（`migrateLegacyWorkflowDirIfNeeded`，不删 legacy）。

## 三、服务端规则

- `normalizeWorkflowDefinition`：prompt 数组 join；`maxRetries` 缺省 2。
- 种子：`builtin_feishu_dev_pipeline` 来自 `resources/template/workflow/example/workflow.yaml`，仅 id 不存在时写入。
- 实例状态：`pending|running|paused|completed|failed`。

## 四、客户端流程

设置页 `WorkflowPanel`「定义」Tab：编辑节点（排序、model、isolated、config）→ IPC `saveWorkflowDefinition` → YAML。启动 → `createInstance` → `instances/{id}.json`。

## 五、接口

| API | 说明 |
|-----|------|
| list/get/save/deleteDefinition | 定义 CRUD |
| parseWorkflowDefinitionText | 自动 JSON/YAML |
| createInstance | 默认 maxSteps=50 |
| get/saveInstance | 实例 JSON |

IPC：`workflow:list-definitions`、`workflow:save-definition`、`workflow:run` 等。

## 六、数据

**Definition**：id, name, description?, workingDirectory?, config?, nodes[], 时间戳。

**Node**：id, name, prompt, model?, maxRetries, isolated?

**Instance**：workflowId, status, currentNodeId, context, nodeHistory, notifyChatId?, workingDirectory, input?, maxSteps, stepCount, **sessionKey?**（isolated 节点 Agent 绑定键，`{notifyChatId||"wf"}::wf_{instanceId}_{nodeId}`，见 `workflow-session-key.ts`）。

**NodeExecution**：nodeId, attempt, status, input, output?, rejectReason?, rejectFromNodeId?

```
workflows/definitions/{id}.yaml
workflows/instances/{uuid}.json
```

## 七、非功能与可观测

读写失败静默降级（`readJsonSafe`）；YAML `lineWidth: 0`。首次 IO 打 `workflow_storage_root=`（`logWorkflowStorageRootOnce`）；`APP_DATA_DIR` 未设时读写 no-op。

## 八、推送

无

## 九、已知限制与 TODO

- UI 存对象非 YAML 文本；与 MCP YAML 创建路径并存。
- 纯 Daemon 冷启动且数据仅在历史 Electron userData 时，须 Electron 侧 `seedBuiltins` 触发迁移（store 无参迁移仅探测 `cwd/workflows`）。
- 工作流 `sessionKey` **不**写入 `session-routing.json`（IM 路由归 Agent 标识域）。
