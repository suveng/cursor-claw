# 工作流 · 触发与管理入口

## 一、能力范围

创建定义、启动/恢复实例、查询状态：设置页、`/workflow` 指令、`POST /api/workflow-signal`、`manage_workflows` MCP。不负责 Agent 侧 next/reject。

## 二、设计决策与取舍

- UI、指令、MCP `run` 均 `createInstance`+`startWorkflow`+`launchWorkflowAgent`（MCP 另 emit stdout 信号）。
- **恢复双端 SSOT**：Electron（UI/斜杠）共用 `resumeWorkflowInstance`（`electron/workflow/workflow-runner.ts`）；Daemon（HTTP）共用 `resumeWorkflowAndEmit`（`src/workflow/server-workflow.ts`，stdout `__WF_LAUNCH__`）。两路径均调引擎 `resumeWorkflow`。
- `notifyChatId`：指令=触发者 chatId；UI=主用户通道 chatKey。
- 定义 CRUD 在 admin MCP（`manage_workflows` 定义于 `src/workflow/server-workflow.ts`，经 `src/daemon/daemon-http-mcp.ts` `createAdminMcpServer` 注册）；流转在 agent MCP（`workflow_next`/`workflow_reject` 同 `server-workflow.ts`，经 `createMcpServer` 注册）。

## 三、服务端规则

**manage_workflows**：list/get/create/update/delete/run/status。`create/update` 解析 YAML/JSON；`run` 建实例并 `__WF_LAUNCH__`。

## 四、客户端流程

`Settings`→tab「工作流」→`WorkflowPanel`：定义（编辑/启动/删）、实例（列表/详情/删）；`WorkflowInstanceDetail` 在 `status===paused` 时展示「恢复」。飞书 `/workflow ls|info|run|resume|status|delete`（resume 经 T10 `executeSlashCommand`→`command/execute`）。

```mermaid
flowchart LR
  U[用户] --> S[设置页]
  U --> F[/workflow]
  U --> H[POST workflow-signal]
  U --> AI[Admin MCP]
  S -->|workflow:resume| WR[resumeWorkflowInstance]
  F -->|resume| WR
  H --> SW[resumeWorkflowAndEmit]
  WR --> ENG[engine]
  SW --> ENG
  AI -->|run| ENG
```

## 五、接口

| 子命令 | 说明 |
|--------|------|
| ls, info \<id\> | 列/查定义 |
| run \<id\> [输入] | 启动 |
| resume \<实例ID\|序号\> | 恢复 paused 实例 |
| status [实例ID] | 查实例 |
| delete \<id\> | 删定义 |

| 通道 | 契约 |
|------|------|
| IPC `workflow:resume` | `{ instanceId }` → `{ ok, error?, instanceId? }`（`daemon-manager.ts`） |
| HTTP `POST /api/workflow-signal` | `{ action:"resume", instanceId }` → 200/400/404/409（见 Daemon §五） |

MCP `manage_workflows` action 见上（**无** `resume` action，HTTP 直连 `resumeWorkflowAndEmit`）；IPC 另有 `workflow:run` 等。

## 六、数据

读写 `workflows/definitions` 与 `instances`，无额外存储。

## 七、非功能与可观测

指令经 `reportCommandResult`；MCP 错误文本返回。

## 八、推送

run 成功通知 `notifyChatId`（UI 主用户/指令操作者）。

## 九、已知限制与 TODO

- `/workflow` 无 create/update。
- MCP create 文案写 JSON，实际支持 YAML。
- 斜杠 resume 实例未命中时文案为「找不到该实例」（引擎路径仍为「实例不存在」）。
