# Agent 调度 · 概览

## 一、模块定位与边界

连接 Daemon 与 Agent（**IM 四引擎**：Cursor SDK / Claude Code SDK / Codex SDK / OpenCode SDK）。Daemon claim 转发 `agent-api` 等；Electron 负责任务/工作流/斜杠 launch。

## 二、整体架构

```mermaid
flowchart TB
  D[Daemon] --> API[agent-api]
  API --> SDK[agent-sdk]
  API -->|codex| CODEX[agent-codex-sdk]
  API -->|cc| CC[agent-claude-sdk]
  API -->|opencode| OC[agent-opencode-sdk]
  CC_API[cc-agent-api] --> CC
  CODEX_API[codex-agent-api] --> CODEX
  OC_API[opencode-agent-api] --> OC
  SD[session-dispatcher] --> CC_API
  SD --> CODEX_API
  SD --> OC_API
  SDK --> D
  CC --> D
  CODEX --> D
  OC --> D
```

## 三、核心状态机/主流程

Idle → claim → launch → processing → resident idle → dispatch → idle/close。Cursor SDK 主进程重启时扫描 `sdk-active-runs.json`，`recoverSdkActiveRuns` 续接 stream 或一次失败提示。

```mermaid
stateDiagram-v2
  [*] --> Idle
  Idle --> Processing: launch/dispatch
  Processing --> Idle: completeSdkRun
  Processing --> Idle: stopSdkSession
  Idle --> Recover: 应用 init
  Recover --> Processing: resume 成功
  Recover --> Idle: 续接失败/已终态
```

## 五、关键约束

IM **四引擎**；无 poll；`workspace-injector` no-op；`SDK_RESIDENT_AGENT` 默认开。Cursor SDK 配置从 `{cwd}/.cursor/` 与 `~/.cursor/` 经 `settingSources` 加载；主进程重启经 `sdk-active-runs.json`+`recoverSdkActiveRuns` 续接（用户停止写 `userStopped` 跳过）。CC `ccSessionId`+`resume`；Codex `codexSessionId`+`resumeThread`；OpenCode `opencodeSessionId`+`session.prompt` 续接。
