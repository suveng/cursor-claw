# Agent 调度 · 概览

## 一、模块定位与边界

连接 Daemon 与 Agent（**IM 三引擎**：Cursor SDK / Claude Code SDK / Codex SDK）。Daemon claim 转发 `agent-api` 等；Electron 负责任务/工作流/斜杠 launch。

## 二、整体架构

```mermaid
flowchart TB
  D[Daemon] --> API[agent-api]
  API --> SDK[agent-sdk]
  API -->|codex| CODEX[agent-codex-sdk]
  API -->|cc| CC[agent-claude-sdk]
  CC_API[cc-agent-api] --> CC
  CODEX_API[codex-agent-api] --> CODEX
  SD[session-dispatcher] --> CC_API
  SD --> CODEX_API
  SDK --> D
  CC --> D
  CODEX --> D
```

## 三、核心状态机/主流程

Idle → claim → launch → processing → resident idle → dispatch → idle/close。

## 四、子模块清单

## 五、关键约束

IM **三引擎**；无 poll；不写盘 inject；`SDK_RESIDENT_AGENT` 默认开；CC `ccSessionId`+`resume`；Codex `codexSessionId`+`resumeThread`。
