# 启动与自动重连

## 一、能力范围

Agent 拉起（`agent-sdk`/`session-dispatcher` 路由 sdk/cc/codex/opencode）、Prompt、Daemon 调度、崩溃自愈。Claude `query()`；Codex `runStreamed`；OpenCode `session.prompt`+SSE（`agent-opencode-sdk.ts`）。

## 二、设计决策与取舍

- **四引擎路由**：IM→`agent-api`→`agent-sdk`；任务/工作流→`launchAgent` 直 POST 各 agent-api。
- **SDK 长驻**：`SDK_RESIDENT_AGENT` 默认开；超时 `finalizeSdkRunOnTimeout`；`acquireRunGuard` 单飞。
- **CC 长驻**：`CC_RESIDENT_AGENT` 默认开；`ccSessionId`+`options.resume`；`cc-mcp-loader` 每次 `query()` 注入。
- **Codex 长驻**：`CODEX_RESIDENT_AGENT` 随 SDK 默认开；`codexSessionId`+`resumeThread`；`codex-mcp-loader` 每次注入。
- **OpenCode 长驻**：`OPENCODE_RESIDENT_AGENT` 随 SDK 默认开；`opencodeSessionId`+`session.prompt`；`opencode-mcp-loader` 每次注入；embedded/external 由 Profile `deployMode` 决定。
- **ContextRotation**：≥90%×2、冷却 3min；CC 清 `ccSessionId`，Codex 清 `codexSessionId`，OpenCode 清 `opencodeSessionId`（`resolveOpencodeContextLimit` 异步写阈值）。
- **失败 notify**：`formatUserSdkFailureMessage`/`formatCodexFailureMessage`；无 launch 注入。
- **Prompt 群名**：四引擎共用 `buildPrompt`（`electron/agent/shared/agent-launcher.ts`）；有群名时首行注入 `group_name: <名>`，无则省略该行（不写空占位）；来源优先显式 `chatName`，否则 `resolveSessionChatName(sessionKey)`（chatNameCache）。

## 三、服务端规则

1. claim→launch/dispatch；`agent_busy` 延后。
2. 模型默认：SDK `composer-2`、Codex `CODEX_DEFAULT_MODEL_ID`；须配 API Key。
3. 超时 finalizer；非超时 `failedCooldowns`+长驻保留。
4. watchdog→cancel→finalizer。
5. CC/Codex/OpenCode 事件映射；端口 `cc-agent-api-port.json`/`codex-agent-api-port.json`/`opencode-agent-api-port.json`；Codex spawn 前 CLI 检测；OpenCode 内嵌 `createOpencode` 失败或外部 `config.get` 探活失败返回用户文案。

## 四、客户端流程

队列/SSE→300ms 防抖→claim→launch/dispatch→Run→complete→idle。

## 五、接口

| 入口 | 说明 |
|------|------|
| Daemon `/api/agent/launch\|dispatch` | IM |
| `launchSessionAgent` 等 | session-dispatcher |
| `launch*Agent`/`dispatchTo*Agent` | 四引擎长驻入口 |

## 六、数据

四引擎端口 json；`SdkSessionAgent`/`CcSessionAgent`/`CodexSessionAgent`/`OpencodeSessionAgent`。

## 七、非功能与可观测

`dispatch_retry`/`watchdog`/`context_rotation`/`dispatch_failed`；`[compression]` UI 日志。

## 八、推送

无。

## 九、已知限制与 TODO

SDK 无 resume；CC `options.resume`；Codex `resumeThread`；OpenCode `session.prompt` 复用 `opencodeSessionId`；Codex 缺 CLI 时用户可见文案；OpenCode 内嵌 server 退出须 `closeAllEmbeddedOpencodeServers`。
