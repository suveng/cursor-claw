# 启动与自动重连

## 一、能力范围

Agent 进程拉起（**IM/任务/工作流均经 session-dispatcher 路由 sdk/cc**）、Prompt 构建、队列驱动调度（**Daemon 编排**）、崩溃自愈。无 Cursor CLI spawn；Claude Code 路径 spawn `claude` CLI（`@anthropic-ai/claude-code`）。

## 二、设计决策与取舍

- **双引擎统一路由**：Daemon orchestrator 统一 `POST /api/agent/launch|dispatch`；Electron 按 `resource.type` 内部分委托 SDK 或 CC。**仅** sdk/cc（`session-dispatcher` L255-257 拒绝其他类型）；无 Cursor CLI spawn。
- **SDK 长驻（T6）**：`SDK_RESIDENT_AGENT` 默认开；非超时 Run 结束保留实例 + idle；超时走 `finalizeSdkRunOnTimeout`；`acquireRunGuard` 单飞。
- **CC 长驻（T3-CC）**：spawn `claude`（`--print`/`--verbose`/`stream-json`）；保留 `ccSessionId`，二次 `--resume`；`pendingDispatch` 防并发。
- **ContextRotation-lite**：`usageRatio >= 90%` 连续 2 次触发，冷却 3 分钟；先建新实例成功再切换。
- **失败可读 notify**：非超时 Run error 经 `formatUserSdkFailureMessage` 归因（禁止仅”请稍后重试”）。
- **无 launch 注入**：`injectWorkspaceToDir` no-op；launch 禁止写 `~/.cursor`/项目 rules。

## 三、服务端规则

1. Daemon claim → launch（首条）或 dispatch（长驻）。
2. `agent_busy` → 按 `retry_after` 延后重排不 ack；其他失败 notify + ack。
3. SDK 默认模型空/auto → `composer-2`；通道须绑定 sdk/cc 资源且配置 API Key。
4. 进程 close：异常退出通知；5min 内连续崩溃 drain 队列（任务路径）。
5. Run 超时：`isRunTimeoutFailure` → `finalizeSdkRunOnTimeout`；`completeSdkRun` 幂等跳过 finalizing session。
6. 非超时 error：写 `failedCooldowns`、长驻保留实例。
7. watchdog：`watchRunGuard` 超时 → `run.cancel + run.wait` → `finalizeSdkRunOnTimeout`。
8. CC 引擎：spawn `claude` CLI；exit code≠0 或无 `result.subtype=success` → notify 失败；端口写 cc-agent-api-port.json。

## 四、客户端流程

队列/SSE → Daemon 300ms 防抖 → claim → 长驻? 是→dispatch / 否→launch → Run → 超时?是→`finalizeSdkRunOnTimeout` / 否→`completeSdkRun` → idle。

## 五、接口

| 入口 | 说明 |
|------|------|
| Daemon `POST /api/agent/launch|dispatch` | IM 统一入口，内部分委托 sdk/cc |
| `launchSessionAgent` / `launchIndependentAgent` / `launchWorkflowAgent` | session-dispatcher 对外入口（sdk/cc 路由） |
| `launchSdkAgent` / `dispatchToSdkAgent` | SDK 长驻 create/dispatch |
| `launchClaudeCodeAgent` / `dispatchToClaudeCodeAgent` | CC 长驻 spawn/dispatch（任务/工作流亦经 cc-agent-api） |
| `dispatchSessionAgents()` | **空实现**（兼容） |

## 六、数据

- `agent-api-port.json`：`{ port }` 于 userData。
- `cc-agent-api-port.json`：`{ port }` 于 userData（CC engine HTTP server 端口）。
- `LaunchAgentOptions` / `SdkSessionAgent`：sessionKey、chatType、residentMode 等。

## 七、非功能与可观测

`dispatch_retry`/`watchdog`/`context_rotation`/`dispatch_failed`/`agent_failed` 可检索；`finalizeSdkRunOnTimeout` WARN 含 trigger/durationMs；`[compression] pre-send usage`/`high-watermark` 写 UI 日志。

## 八、推送

无。

## 九、已知限制与 TODO

- ContextRotation-lite 固定摘要模板，后续可接真实摘要生成。
- Windows spawn 需 `quoteArg`。
