# 启动与自动重连

## 一、能力范围

Agent 拉起（session-dispatcher 路由 sdk/cc）、Prompt、Daemon 调度、崩溃自愈。无 Cursor CLI spawn；Claude Agent 经 `@anthropic-ai/claude-agent-sdk` `query()`（`agent-claude-sdk.ts`）。

## 二、设计决策与取舍

- **双引擎路由**：Daemon `POST /api/agent/launch|dispatch`；Electron 按 `resource.type` 委托 SDK/CC；仅 sdk/cc。
- **SDK 长驻**：`SDK_RESIDENT_AGENT` 默认开；非超时保留实例；超时 `finalizeSdkRunOnTimeout`；`acquireRunGuard` 单飞。
- **CC 长驻**：`CC_RESIDENT_AGENT` 默认开（`0` 关）；Run 结束保留 Map；`ccSessionId` 来自 SDK `system/init`/`result`，续跑经 `options.resume`；`pendingDispatch` 防并发。
- **CC MCP**：`cc-mcp-loader` 合并 mcp.json+OAuth；每次 `query()` 重传 `mcpServers`。
- **ContextRotation-lite**：占用 ≥90% 连续 2 次、冷却 3min；CC 轮转清 `ccSessionId`。
- **失败 notify**：非超时 error 经 `formatUserSdkFailureMessage` 归因。
- **无 launch 注入**：`injectWorkspaceToDir` no-op。

## 三、服务端规则

1. claim → launch/dispatch；`agent_busy` 按 `retry_after` 延后。
2. SDK 默认模型空/auto → `composer-2`；通道须绑定 sdk/cc 且配 API Key。
3. 超时 → `finalizeSdkRunOnTimeout`；非超时 error → `failedCooldowns`+长驻保留。
4. watchdog 超时 → cancel → finalizer。
5. CC：`agent-cc-events.ts` 映射 SDKMessage；`lastStatus=ERROR` 或非零 exitCode → 失败 notify；端口写 `cc-agent-api-port.json`。

## 四、客户端流程

队列/SSE → 300ms 防抖 → claim → launch/dispatch → Run → finalizer 或 complete → idle。

## 五、接口

| 入口 | 说明 |
|------|------|
| Daemon `/api/agent/launch\|dispatch` | IM 统一入口 |
| `launchSessionAgent` 等 | session-dispatcher（sdk/cc） |
| `launchSdkAgent` / `dispatchToSdkAgent` | SDK 长驻 |
| `launchClaudeCodeAgent` / `dispatchToClaudeCodeAgent` | CC query/dispatch（cc-agent-api） |

## 六、数据

- `agent-api-port.json` / `cc-agent-api-port.json`：`{ port }` 于 userData。
- `SdkSessionAgent` / `CcSessionAgent`：sessionKey、residentMode、ccSessionId 等。

## 七、非功能与可观测

`dispatch_retry`/`watchdog`/`context_rotation`/`dispatch_failed` 可检索；`[compression] pre-send usage`/`high-watermark` UI 日志。

无。
