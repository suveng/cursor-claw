# 启动与自动重连

## 一、能力范围

Agent 拉起（`agent-sdk`/`session-dispatcher` 路由 sdk/cc/codex/opencode）、Prompt、Daemon 调度、崩溃自愈。四引擎对照：Cursor SDK create/send；Claude `startCcSpawn`（`spawnClaudeCodeProcess`+`query` 桥，`CC_LEGACY_QUERY` 可降级）；Codex `runStreamed`；OpenCode `session.prompt`+SSE。

## 二、设计决策与取舍

- **四引擎统一网关**：IM/任务/工作流/`/chat new` 经 `agent-sdk-http`；init 仅 `ensureAgentSdkHttpServer` 常驻。
- **长驻 Agent**：四引擎默认 resident；`enterGuardWithLifecycle` 单飞；超时各引擎 finalizer。
- **主进程续接（S7）**：`recoverAllActiveRuns` 读快照；三引擎 guard 前探活+分类 IM；CC 续接入口 `startCcSpawn`；`userStopped` 不续接。
- **ContextRotation**：≥90%×2、冷却 3min；ratio≥100% 首轮即轮转。
- **群名入队拼尾**：`pushMessage` 前 `resolveLaunchChatName`；有名则 `\ngroup_name: <名>`。
- **SDK 冷启动进度（B2）**：`starting`→「正在连接 Agent…」；create 后「正在准备模型…」；`agent.send` 后「Agent 处理中…」。
- **bind 预热（B1）**：`warmupSdkAfterBind`→`POST /api/sdk-warmup`；fire-and-forget。
- **空闲预热（长驻）**：空闲 ≥15min 后台 `resident-bg-warmup` recreate + 发前 `resident-refresh` 双保险；多会话串行节流。详见 [[06-CursorSDK执行引擎]]。Claude 进程生命周期与 pid 见 [[07-ClaudeCodeSDK执行引擎]]。

## 三、服务端规则

1. claim→launch/dispatch；`agent_busy` 延后。
2. 模型默认：SDK `composer-2`、Codex `CODEX_DEFAULT_MODEL_ID`；须配 API Key。
3. 超时 finalizer；非超时 `failedCooldowns`+长驻保留。
4. watchdog→cancel→finalizer（CC 另 `killCcSpawnedProcess`）。
5. 非 SDK 引擎 per-engine 端口 json 仅显式拉起 HTTP 时写入。

## 四、客户端流程

队列/SSE→300ms 防抖→claim→launch/dispatch→Run→complete→idle。

```mermaid
flowchart LR
  enqueue[入队确认] --> connect["正在连接 Agent…"]
  connect --> prepare["正在准备模型…"]
  prepare --> processing["Agent 处理中…"]
```

三态 notify **不带** `message_id`/`stop_progress`。processing 入队 F1 文案见 [[业务域/消息桥接/04-消息队列与路由]]（「已排队，当前任务结束后处理」）。

## 五、接口

| 入口 | 说明 |
|------|------|
| Daemon `/api/agent/launch\|dispatch` | IM 转发 Electron |
| Electron `POST /api/sdk-warmup` | bind 跨进程预热 |
| `launchSessionAgent` 等 | 本地经 `launchSdkAgentFromHttp` |

## 六、数据

四引擎端口 json；四份 `*-active-runs.json`；四引擎 session 类型（见 06–09；CC 含内存 `childPid`/`spawnedProcess`）。

## 七、非功能与可观测

`dispatch_retry`/`watchdog`/`context_rotation`/`dispatch_failed`；`[compression]`；`[recover]`；`[sdk_warmup]`/`[resident-bg-warmup]`；CC `cc_spawn pid=` / `cc_spawn_*` / `legacy_query`。

## 八、推送

无。

## 九、已知限制与 TODO

SDK 无 SDK 内 resume；CC/Codex/OpenCode 各 sessionId 续上下文；Codex CLI 缺失逐条 notify。
