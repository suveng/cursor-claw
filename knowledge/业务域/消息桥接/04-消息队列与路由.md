# 消息队列与路由

## 一、能力范围

file-queue、sessionKey、ack、F1、**MergeBatch**、**Daemon dispatch**、SDK 流式 **final ack**、Presentation/stream 出站、SSE。

**不负责**：SDK Run 内部、CardKit 渲染细节（见 [[02-飞书通道]]）。

## 二、设计决策与取舍

- **源码**：`file-queue.ts` 薄组装；子模块 path/types/message-io/enqueue/claim/lifecycle/query。
- 原子入队；`.qmsg→.claimed`；`ackOnReply` 删该 id 及更早项。
- **T7**：入队/SSE → `scheduleAgentDispatch`(300ms)；**无 poll**。
- **MergeBatch**：≥2 collecting → 静默 → ready → claim；落点 `daemon-queue*`。
- **入队文案 SSOT**：`buildEnqueueStatusText`（`daemon-presentation-enqueue`）：
  - `starting` →「已排队，当前连接结束后处理」
  - `processing` →「已排队，当前任务结束后处理」
  - idle：单条「已收到，等待 Agent 领取」；多条「已收到，已加入待处理队列」
  - 禁止复述「正在连接 Agent…」「Agent 处理中…」；合并卡 ready+processing footer 同词根。

## 三、服务端规则

- **入队门槛**：飞书群 `isBotMentioned`；微信群 `shouldEnqueueWechatGroupMessage`；私聊不经群 gate。
- F1：`shouldSendEnqueueF1` suppress collecting 第 2+ 条；排队数 `getSessionUnclaimedCount`（`.qmsg`）；`phase` 缺省 `idle`。
- claim：ready 合并或单条；`overrideText` 优先。
- **launch/dispatch 失败**：`handleLaunchFailure`；busy/瞬时 release→retry；未耗尽不 ack。
- **stream-text**：中间不 ack；`final` 飞书先关 CardKit streaming 再 ack。
- `POST /api/merge-batch/action`；`POST /api/presentation-event`；`GET /api/poll-message` **404**。

## 四、客户端流程

pushMessage → MergeBatch → dispatch → claim → launch|dispatch → SDK 流式 → final `ackOnReply` → Presentation。飞书入队确认后可启动长任务心跳（见 [[02-飞书通道]]）。

## 五、接口

| 路径/函数 | 说明 |
|-----------|------|
| `/api/agent/launch\|dispatch` | 转发 agent-api；可选 `message_ids` |
| `/api/stream-text` | 流式；`final` + 可选 `message_id` ack |
| `/api/presentation-event` / `/api/session-agent-phase` | Presentation / 阶段 |
| `pushToFileQueue` / `claimSessionMessages` / `ackMessages` | 入队/领取/ack |
| `buildEnqueueStatusText` / `confirmEnqueueAndStartProgress` | F1 与进度启动 |

## 六、数据

`.qmsg/.claimed`；`mergeBatchBySession`、`sessionAgentPhaseMap`、`sessionProgressMap`。

## 七、非功能与可观测

`dispatch_failed`、`dispatch_retry_*`、`agent_busy_requeue`、`presentation_failed`；节流 500–1500ms。

## 八、推送

SSE queue-update。

## 九、已知限制与 TODO

按钮回调边界；任务 launch 仍走 Electron；并发多进程 claim 压测未自动化。
