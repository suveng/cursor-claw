# 消息队列与路由

## 一、能力范围

file-queue、sessionKey、ack、F1、**MergeBatch**、**Daemon dispatch**、SDK 流式 **final ack**、Presentation/stream 出站、SSE。

**不负责**：SDK Run 内部、CardKit 渲染（见 [02](./02-飞书通道.md)）。

## 二、设计决策与取舍

- **源码结构**：`file-queue.ts` 薄组装；子模块 path/types/message-io/enqueue/claim/lifecycle/query；域外仍 `file-queue.js`（`AGENTS.md`）。
- 原子入队；`.qmsg→.claimed`；`ackOnReply` 删该 id 及更早项。
- **lifecycle**（`file-queue-lifecycle.ts`）：`releaseClaimedMessages` `.claimed→.qmsg`；`ackMessages` 删 `.claimed`；`cleanupOrphanClaimedOnColdStart` 冷启动还原。
- **SDK final ack**：final stream-text 传末条 inbound id → `daemon-presentation-stream.ts` `ackOnReply`；resident 仅 ack 当次 batch 末条。
- **T7**：SSE/入队 → `daemon-orchestrator.ts` `scheduleAgentDispatch`(300ms) → agent-api；**无 poll**。
- **MergeBatch**：≥2 collecting → 静默 → ready → claim；processing/静默期 defer。

## 三、服务端规则

- F1：`shouldSendEnqueueF1` suppress collecting 第 2+ 条；排队数仅 `getSessionUnclaimedCount`（`.qmsg`）；`phase` 缺失默认 `idle`。
- claim：ready 合并或单条；`overrideText` 优先。
- **launch/dispatch 失败**（IM `dispatchSessionToAgent` 与 HTTP `POST /api/agent/dispatch`）：共用 `handleLaunchFailure`；busy/瞬时 `releaseClaimedMessages`→`scheduleDispatchRetry`（3 次；600/1200/2400ms）；**未耗尽禁止 ack**；耗尽 notify→ack；`ok` 清零 attempt。日志 `dispatch_retry_*`/`agent_busy_requeue`。
- **stream-text**：中间不 ack；`final` 飞书先关 CardKit streaming 再 ack；CardKit 失败降级 PATCH/分段。
- claim 得 `message_ids` 经 `forwardElectronAgentApi` 传 launch/dispatch。
- `POST /api/merge-batch/action`；`POST /api/presentation-event`；`GET /api/poll-message` **404**。

## 四、客户端流程

pushMessage → MergeBatch → dispatch loop → claim → agent/launch|dispatch → SDK 流式 → final `ackOnReply` → Presentation。launch 失败则 release→延后再 claim；耗尽后 ack。

## 五、接口

| 路径/函数 | 说明 |
|-----------|------|
| `/api/agent/launch\|dispatch` | 转发 agent-api；可选 `message_ids` |
| `/api/stream-text` | 流式；`final` + 可选 `message_id` ack |
| `/api/merge-batch/action` / `/api/presentation-event` / `/api/session-agent-phase` | 合并 / Presentation / 阶段 |
| `pushToFileQueue` | 入队+dedup → `file-queue-enqueue.ts` |
| `claimSessionMessages` | 领取 → `file-queue-claim.ts` |
| `ackMessages` / `releaseClaimedMessages` | ack 删 / release 重入队 → `file-queue-lifecycle.ts` |
| `getSessionUnclaimedCount` 等 | 计数/列表 → `file-queue-query.ts` |
| `createDispatchRetry` / `handleLaunchFailure` | 有限重试与耗尽 ack |
| `performClaimAndMerge` | claim 合并 |

## 六、数据

`.qmsg/.claimed`；`mergeBatchBySession`、`sessionAgentPhaseMap`、`sessionProgressMap`（CardKit 字段）。重试 attempt 仅进程内 Map（`daemon-orchestrator-retry.ts`）。

## 七、非功能与可观测

`dispatch_failed`、`dispatch_retry_scheduled`、`dispatch_retry_exhausted`、`agent_busy_requeue`、`presentation_failed`；节流 500–1500ms。
