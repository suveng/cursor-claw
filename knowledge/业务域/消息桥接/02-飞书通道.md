# 飞书通道

## 一、能力范围

飞书 WS、`LarkSender` post/md 出站、Get/DONE、合并预览；assistant 飞书 f41 Run 收尾 plain send-text；私聊菜单、进入私聊帮助、扫码开权。

**Presentation**：抑制 CardKit→里程碑 `sendMilestoneText`（≥3s）；f41 assistant 收尾 plain `send-text`。长静默：**CardKit settings 续期**或轻量「仍在处理中…」心跳；**禁止**假 SDK turn。

**不负责**：Daemon dispatch、凭据 UI、微信、飞书后台菜单配置。

## 二、设计决策与取舍

- 出站 post/md：含 `<at` 降级 text；群聊可选 title；CardKit 经 gate 抑制。
- assistant：f41 plain；非 f41 `stream-text`+update。合并预览静默 2.5s。
- 过程门控：tool/task→里程碑（`started`「正在执行：…」）；thinking 零 IM，ordering 仍置闩。
- **长任务心跳**：`lark-cardkit-renewal` + `daemon-presentation-feishu-heartbeat`；优先流式/工具/思考卡 `renewStreamingCardSettings`；无卡则 milestone「仍在处理中…」；入队确认启动、出站 `noteOutbound`、stop 清 timer。
- **源码**：域外仅 `import "../bridge/lark-core.js"`；实现在 `lark-*.ts`；daemon 禁止直引 `lark-sender-*`。

| 文件 | 职责 |
|------|------|
| `lark-sender-stream` | CardKit 流式 create/send/PATCH/close/`renewStreamingCardSettings` |
| `lark-cardkit-renewal` | 会话心跳 Map+interval（禁止假 turn） |
| `lark-sender-outbound` / `merge` / `progress` | plain；合并卡；工具/思考卡 |
| `lark-sender-parse` / `connection` | 入站；WS |

### 多引擎飞书契约

| 层 | 规则 |
|---|---|
| Electron | presentation 禁止飞书早退；tool stuck 提示不传 `stop_progress` |
| Daemon | thinking 零里程碑；tool/task→`sendMilestoneText`；心跳续期 |
| 终态 | `notifySessionChat`；`stop_progress` |
| busy S8 | `notifyGuardBusy` 一次 IM + `stop_progress` |

## 三、服务端规则

群聊须 @；F1 三态；orphan claimed 回收；F3 override；菜单→`handleSlashCommand`（`source=menu`）。

**卡片回调**：`card.action.trigger`→`handleMergeBatchAction`；`return await` 透传 toast。

**入队正文**：有 `chatType` 时拉名，成功则 append `\ngroup_name: <名>`。

## 四、客户端流程

入站→F1/合并→dispatch→Presentation（含心跳）→assistant（f41 plain；否则 stream-text）。

## 五、接口

门面 `LarkSender`；`renderMergeBatchCard`、`sendMilestoneText`、`renewStreamingCardSettings`、`feishu-plain-assistant-reply`。

## 六、数据

`MergeBatch`、`mergeCardRegistry`、`SessionProgressState`（含 CardKit 序列）、`helpThrottleMap`。

## 七、非功能与可观测

CardKit/里程碑降级；stream-text 500–1500ms、里程碑 ≥3s；心跳与 milestone 节流协调。

## 八、推送

无。

## 九、已知限制与 TODO

群聊无自定义菜单；须订阅 `card.action.trigger`。心跳不伪造 SDK turn。
