# 飞书通道

## 一、能力范围

飞书 WS、`LarkSender` **post/md 出站**（默认 Markdown 渲染）、Get/DONE、合并预览文本；assistant 飞书 f41 为 Run 收尾 plain send-text；私聊菜单、进入私聊帮助文本、扫码开权（增量 scopes 含通讯录读权限）。

**Presentation**：飞书抑制 CardKit→里程碑 `sendMilestoneText`（3s，post/md）；飞书 f41 assistant Run 收尾 plain `send-text`。

**不负责**：Daemon dispatch、凭据 UI、微信、飞书后台菜单配置。

## 二、设计决策与取舍

- **出站统一 post/md**：`sendMessage`/`sendStreamMessage`/`updateMessageContent` 默认 `msg_type: post` + `md` 标签（Markdown 渲染）；含 `<at user_id=` 时降级 `text`；群聊可选 `post.title` 工作区名，**私聊不加**工作区前缀；**不再**发送 interactive 卡片或 CardKit 流式卡（工具/思考 CardKit 渲染代码保留但飞书路径已被 presentation gate 抑制）。
- assistant：飞书 f41（`f41Stream`+feishu）plain 收尾——delta 只累积 buffer；Run 收尾 `feishu-plain-assistant-reply`→`send-text`。非 f41  eligible 仍走 `stream-text`，但 daemon 侧为 plain text 首包 + `im.message.update` 增量更新。
- **四引擎**共用 `feishu-plain-assistant-reply`；飞书 plain 时 `appendAssistantStreamDelta` 只写 buffer。
- **合并预览**：plain text 首包 + `updateMessageContent` 增量更新；`MERGE_QUIET_MS` 2.5s；NF2 reply 末条 inbound。
- **帮助**：进入私聊 `sendHelpCard`→`sendMessage` post/md（24h 节流不变）。
- **eligible**：主用户 p2p + 群聊 `allowOthers`。
- **过程门控**：daemon 抑制 CardKit；tool/task 里程碑经 `sendMilestoneText`→`sendMessage`（post/md）；thinking 零 IM 但 ordering 时 daemon 仍置闩。

### 多引擎飞书契约

| 层 | 规则 |
|---|---|
| Electron | `postPresentationEvent` 禁止飞书早退；thinking/tool notify 始终 POST+`markProcessEventSeen`；silent 跳过 |
| Daemon | thinking 零里程碑；ordering 置 `thinkingOpen`/`presentationProcessActive`；tool/task→`sendMilestoneText` |
| 范围 | 四引擎过程通知与 assistant plain 收尾对齐 |

## 三、服务端规则

群聊须 @；F1 三态排队；orphan claimed 回收；F3 合并预览 override；非 f41 stream-text 为 plain text 首包 + update；菜单 `event_key`→斜杠→`.fcmd`。

## 四、客户端流程

入站→F1/合并预览→dispatch→Presentation（飞书过程里程碑 post/md）→assistant（飞书 f41 plain send-text；否则 stream-text post/md update）。

## 五、接口

`renderMergeBatchCard`、`isFeishuProcessPresentationSuppressed`、`sendMilestoneText`、`feishu-plain-assistant-reply`、`feishu-menu.ts`。

## 六、数据

## 七、非功能与可观测

CardKit/里程碑降级；`milestone_fallback`/`presentation_failed`；stream-text 500–1500ms、里程碑 3s 节流；text update 失败→分段发送。

**扫码增量权限**：`FEISHU_MENU_SCOPES`（`src/shared/feishu-addons.ts`）含 `contact:contact.base:readonly`（获取用户名/私聊会话显示），经 `FEISHU_MENU_ADDONS.scopes.tenant` map 派生；与创建侧 `REQUIRED_FEISHU_SCOPES` 分列、不合并。
