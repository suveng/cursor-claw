# 飞书通道

## 一、能力范围

飞书 WS、`LarkSender` 出站、Get/DONE、合并卡；assistant 非飞书 f41 为 CardKit 流式，飞书 f41 为 Run 收尾 plain send-text；私聊菜单、进入私聊帮助卡、扫码开权。

**Presentation**：飞书抑制 CardKit→里程碑 `sendMilestoneText`（3s）；飞书 f41 assistant Run 收尾 plain `send-text`。

**不负责**：Daemon dispatch、凭据 UI、微信、飞书后台菜单配置。

## 二、设计决策与取舍

- assistant：飞书 f41（`f41Stream`+feishu）plain 收尾——delta 只累积 buffer、不 POST stream-text；Run 收尾 `feishu-plain-assistant-reply`→`send-text`（`message_id`+`stop_progress`）。非飞书 f41 仍 CardKit 流式。
- **四引擎**（SDK/CC/Codex/OpenCode）共用 plain 模块；飞书 plain 时 `appendAssistantStreamDelta` 只写 buffer。
- **合并卡**单卡 PATCH；`MERGE_QUIET_MS` 2.5s；NF2 reply 末条 inbound。
- **eligible**：主用户 p2p + 群聊 `allowOthers`。
- **过程门控**：daemon 抑制 CardKit；tool/task 里程碑 sent 时 mirror 编排字段；thinking 零 IM 但 ordering 时 daemon 仍置 `thinkingOpen`/`presentationProcessActive`。
- **里程碑**：`sendMilestoneText`；task 不参与 defer。

### 多引擎飞书契约

| 层 | 规则 |
|---|---|
| Electron | `postPresentationEvent` 禁止飞书早退；thinking/tool notify 始终 POST+`markProcessEventSeen`；silent 跳过 |
| Daemon | thinking 零里程碑；ordering 置 `thinkingOpen`/`presentationProcessActive`；tool/task→`sendMilestoneText` |
| 范围 | 四引擎过程通知与 assistant plain 收尾对齐 |

## 三、服务端规则

群聊须 @；F1 三态排队；orphan claimed 回收；F3 合并卡 override；assistant 非飞书 f41 为 CardKit 四步流式；菜单 `event_key`→斜杠→`.fcmd`。

## 四、客户端流程

入站→F1/合并卡→dispatch→Presentation（飞书过程里程碑）→assistant（飞书 f41 plain send-text；否则 CardKit stream-text）。

## 五、接口

`renderMergeBatchCard`、`isFeishuProcessPresentationSuppressed`、`sendMilestoneText`、`feishu-plain-assistant-reply`、`feishu-menu.ts`。

## 六、数据

`MergeBatch`、`mergeCardRegistry`、`SessionProgressState`、`helpThrottleMap`。

## 七、非功能与可观测

CardKit/里程碑降级；`milestone_fallback`/`presentation_failed`；流式 500–1500ms、里程碑 3s 节流。
