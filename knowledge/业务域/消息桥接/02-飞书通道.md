# 飞书通道

## 一、能力范围

飞书 WS、`LarkSender` **post/md 出站**（默认 Markdown 渲染）、Get/DONE、合并预览文本；assistant 飞书 f41 为 Run 收尾 plain send-text；私聊菜单、进入私聊帮助文本、扫码开权（增量 scopes 含通讯录读权限）。

**Presentation**：飞书抑制 CardKit→里程碑 `sendMilestoneText`（3s，post/md）；飞书 f41 assistant Run 收尾 plain `send-text`。

**不负责**：Daemon dispatch、凭据 UI、微信、飞书后台菜单配置。

## 二、设计决策与取舍

- **出站 post/md**：含 `<at` 降级 text；群聊可选 title，私聊不加；CardKit 经 gate 抑制。
- assistant：f41 plain `send-text`；非 f41 `stream-text`+update。
- **四引擎**共用 `feishu-plain-assistant-reply`；合并预览 `MERGE_QUIET_MS` 2.5s。
- **过程门控**：tool/task→`sendMilestoneText`；thinking 零 IM，ordering 仍置闩。

### 多引擎飞书契约

| 层 | 规则 |
|---|---|
| Electron | `postPresentationEvent` 禁止飞书早退；thinking/tool notify 始终 POST+`markProcessEventSeen`；silent 跳过 |
| Daemon | thinking 零里程碑；ordering 置 `thinkingOpen`/`presentationProcessActive`；tool/task→`sendMilestoneText` |
| 终态 IM | 四引擎共用 `run-notify.notifySessionChat`；失败文案 `formatRunFailureMessage`；`stop_progress: true` 停进度 |
| guard busy（S8） | 四引擎 `enterGuardWithLifecycle` busy→`notifyGuardBusy`（`session_abnormal`）一次 IM + `stop_progress`；handler 不二次 notify |
| 契约验收（D3） | `npm run test:run-notify-contract` mock `send-text`，断言 S1/S4/S5/S7/S8 终态与 busy 语义 |
| dispatch 对称 | `daemon-http-routes-orchestrator` 非 busy 调度失败与 launch 失败同类 `notifySessionUser`（`daemon-orchestrator-notify.ts`） |
| 范围 | 四引擎过程通知与 assistant plain 收尾、终态失败/取消/超时/busy 语义对齐 |

## 三、服务端规则

群聊须 @；F1 三态排队；orphan claimed 回收；F3 合并预览 override；非 f41 stream-text 为 plain text 首包 + update；菜单 `event_key`→斜杠→`.fcmd`。

**入队正文**：`pushMessage` 有 `chatType` 时入队前拉名；有名则正文末尾 append `\ngroup_name: <名>`（群名/私聊对方显示名），无名/失败不拼、不阻断（`chat-name-resolve.ts`）。

## 四、客户端流程

入站→F1/合并预览→dispatch→Presentation（飞书过程里程碑 post/md）→assistant（飞书 f41 plain send-text；否则 stream-text post/md update）。

## 五、接口

`renderMergeBatchCard`、`isFeishuProcessPresentationSuppressed`、`sendMilestoneText`、`feishu-plain-assistant-reply`、`feishu-menu.ts`。

## 六、数据

`MergeBatch`、`mergeCardRegistry`、`SessionProgressState`、`helpThrottleMap`。

## 七、非功能与可观测

CardKit/里程碑降级；`milestone_fallback`/`presentation_failed`；stream-text 500–1500ms、里程碑 3s 节流；text update 失败→分段发送。

**扫码权限**：`FEISHU_MENU_SCOPES` 含 `contact:user.base:readonly`（`src/shared/feishu-addons.ts`）。
