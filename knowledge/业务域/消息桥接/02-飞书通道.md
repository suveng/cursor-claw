# 飞书通道

## 一、能力范围

飞书 WS、`LarkSender` 出站、Get/DONE、合并/assistant 流式 CardKit；私聊菜单、进入私聊帮助卡、扫码开权。

**Presentation**：飞书抑制 CardKit → 里程碑 `sendMilestoneText`（3s 节流）；assistant stream-text 不变。

**不负责**：Daemon dispatch、凭据 UI、微信、飞书后台菜单配置。

## 二、设计决策与取舍

- assistant **首选 CardKit 流式**；失败 PATCH/分段。
- **合并卡**单卡 PATCH；`MERGE_QUIET_MS` 2.5s；NF2 活跃批次时 Presentation reply 末条 inbound。
- **eligible**：主用户 p2p + 群聊 `allowOthers`。
- **过程门控**（`feishu-presentation-gate.ts`）：daemon 抑制 CardKit；**ordering 闩由 Electron `markProcessEventSeen` 置位**，与飞书里程碑出站解耦。
- **里程碑**（`daemon-presentation-milestone.ts`）：`sendMilestoneText`；task handler 不参与 defer。

### 多引擎飞书过程通知统一契约

**基准**：Cursor SDK（`electron/agent/cursor-sdk/AGENTS.md` §Presentation）。

| 层 | 规则 |
|---|---|
| Electron | `postPresentationEvent` **禁止**飞书早退；thinking 始终 POST + `markProcessEventSeen(session, kind)`；tool notify 同序，silent 跳过 mark+POST |
| Daemon | thinking 飞书**零里程碑**（`handleThinkingPresentationEvent`）；tool/task → `sendMilestoneText`（`formatToolMilestoneText`） |
| 分级 | `resolveSdkToolPresentationTier`（先 `normalizePresentationToolName`）：notify=shell/write/strreplace/delete/task；silent=read/glob 等 |
| 字段 | `tool_shell_command`、`tool_task_description`；Task 无描述时 `#N` 序号降级 |
| 去重 | `tool-presentation-dedup.ts` 相邻 running 去重 |
| 范围 | **CC 已对齐**；Codex/OpenCode 仍飞书早退（后续） |

## 三、服务端规则

群聊须 @；F1 三态排队文案；冷启动 orphan claimed 回收；F3 合并卡 override；assistant CardKit 四步流式；菜单 `event_key`→斜杠→`.fcmd`。

## 四、客户端流程

入站→F1/合并卡→dispatch→Presentation→assistant 出站（飞书抑制时里程碑 send-text）。

## 五、接口

`renderMergeBatchCard`、`isFeishuProcessPresentationSuppressed`、`sendMilestoneText`、`feishu-menu.ts`、`feishu-event-handlers.ts`。

## 六、数据

`MergeBatch`、`mergeCardRegistry`、`SessionProgressState`、`helpThrottleMap`。

## 七、非功能与可观测

CardKit/里程碑降级；`milestone_fallback`/`presentation_failed`；流式 500–1500ms、里程碑 3s 节流。
