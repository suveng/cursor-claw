# 飞书通道

## 一、能力范围

飞书 WS、`LarkSender` 出站、Get/DONE、合并/assistant 流式 CardKit；私聊菜单（`menu_v6`）；进入私聊帮助卡；设置页扫码开权。

**Presentation**（thinking/tool/task）：飞书抑制 CardKit → **里程碑 send-text**（`sendMilestoneText`）；3s 节流、同文案 ≤4/Run；assistant stream-text 不变；微信走 CardKit。

**不负责**：Daemon dispatch、凭据 UI、微信、飞书后台菜单结构配置。

## 二、设计决策与取舍

- assistant stream-text **首选 CardKit 流式**；失败 PATCH/分段（`lark-core`/`daemon`）。
- **合并卡**单卡 PATCH；按钮占位 T8。
- **静默** `MERGE_QUIET_MS` 2.5s；ready 时 processing 排队。
- **NF2**：活跃 MergeBatch 时 Presentation reply 末条 inbound。
- **eligible**：主用户 p2p + 群聊 `allowOthers`（S1.8）。
- **过程门控**（`feishu-presentation-gate.ts`）：抑制 tool/thinking/task CardKit；**抑制路径不置 ordering 闩**（仅 CardKit 成功路径 defer assistant）。
- **里程碑**（`daemon-presentation-milestone.ts`）：`sendMilestoneText`；`handleTaskPresentationEvent` 映射 task，不参与 defer。
- **菜单**：`event_key`→斜杠→`.fcmd`；无角色门控；帮助卡 24h 节流；须飞书后台配 key。

## 三、服务端规则

- 群聊须 @；F1 `buildEnqueueStatusText`（三态；排队数仅 `.qmsg`）。
- **压缩/失败 notify**：`summary-started` 发压缩提示；失败 `stop_progress`；`summary-completed` 仅 UI。
- **冷启动**：phase 空默认 `idle`；`cleanupOrphanClaimedOnColdStart` 回收 stale `.claimed`。
- **F3**：`mergeCardRegistry` 命中 → override 不入队。
- **合并卡**：预览+脚本；edit 经 `replaceSessionUnclaimedMessages`。
- **assistant 流式**：CardKit 四步；失败/含@ PATCH/分段；ordering defer 仅可见过程卡路径。
- **菜单/进入私聊**：`lark-core` 注册 menu/进入事件；`feishu-event-handlers` 接线；未知 key 文本回复。

## 四、客户端流程

入站→F1/合并卡→dispatch→Presentation→assistant 出站（飞书抑制时里程碑 send-text）。菜单直映射斜杠入 `.fcmd`；进入私聊帮助卡（24h 节流）。

## 六、数据

`MergeBatch`、`mergeCardRegistry`、`SessionProgressState`；`helpThrottleMap`（openId→帮助卡时间，进程内）。

## 七、非功能与可观测

CardKit/里程碑降级；`milestone_fallback`/`presentation_failed`；须 `cardkit:card:write`；edit 30000 字；流式 500–1500ms、里程碑 3s 节流。
