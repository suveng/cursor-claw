# 飞书通道

## 一、能力范围

飞书 WS、`LarkSender` post/md 出站、Get/DONE、合并预览；assistant 飞书 f41 Run 收尾 plain send-text；私聊菜单、进入私聊帮助、扫码开权。

**Presentation**：抑制 CardKit→里程碑 `sendMilestoneText`（3s）；f41 assistant 收尾 plain `send-text`。

**不负责**：Daemon dispatch、凭据 UI、微信、飞书后台菜单配置。

## 二、设计决策与取舍

- 出站 post/md：含 `<at` 降级 text；群聊可选 title；CardKit 经 gate 抑制。
- assistant：f41 plain；非 f41 `stream-text`+update。四引擎共用 `feishu-plain-assistant-reply`；合并预览静默 2.5s。
- 过程门控：tool/task→里程碑；thinking 零 IM，ordering 仍置闩。
- **源码**：域外仅 `import "../bridge/lark-core.js"`。`lark-core.ts` 为 `LarkSender` 门面 + re-export（≤300）；实现在邻接 `lark-*.ts`（均 ≤300）；daemon 禁止直引 `lark-sender-*`。

| 文件 | 职责 |
|------|------|
| `lark-types` / `lark-utils` | 类型；缓存、代理、`createLarkClient` |
| `lark-sender-stream` | CardKit 流式 create/send/PATCH/close |
| `lark-sender-outbound` | plain/post+md、回复、表情、媒体 |
| `lark-sender-merge` | 合并批次卡 |
| `lark-sender-progress` / `help` | 工具/思考卡；帮助卡 |
| `lark-sender-parse` / `connection` | 入站解析；WS `startConnection` |

### 多引擎飞书契约

| 层 | 规则 |
|---|---|
| Electron | 四引擎 presentation 禁止飞书早退；notify 置闩；silent 跳过 |
| Daemon | thinking 零里程碑；tool/task→`sendMilestoneText` |
| 终态 | `run-notify.notifySessionChat`；失败文案；`stop_progress` |
| busy S8 | `notifyGuardBusy` 一次 IM + `stop_progress` |
| 验收 | `npm run test:run-notify-contract`（S1/S4/S5/S7/S8） |
| dispatch | 非 busy 失败与 launch 失败同类 `notifySessionUser` |

## 三、服务端规则

群聊须 @；F1 三态；orphan claimed 回收；F3 override；非 f41 plain 首包+update；菜单→斜杠 `handleSlashCommand`（`source=menu`）。

**卡片回调**：`card.action.trigger`→`onFeishuCardAction`→`handleMergeBatchAction`；`return await` 透传 toast。须订阅 `FEISHU_MENU_EVENTS`。

**入队正文**：有 `chatType` 时拉名，成功则 append `\ngroup_name: <名>`（`chat-name-resolve.ts`）。

## 四、客户端流程

入站→F1/合并→dispatch→Presentation→assistant（f41 plain；否则 stream-text）。

## 五、接口

门面 `LarkSender`（签名稳定）；`renderMergeBatchCard`、`sendMilestoneText`、`feishu-plain-assistant-reply`、`feishu-menu.ts`。类型/工具仍从 `lark-core.js` re-export。

## 六、数据

`MergeBatch`、`mergeCardRegistry`、`SessionProgressState`、`helpThrottleMap`。

## 七、非功能与可观测

CardKit/里程碑降级；stream-text 500–1500ms、里程碑 3s；扫码见 `FEISHU_MENU_SCOPES`/`EVENTS`。
