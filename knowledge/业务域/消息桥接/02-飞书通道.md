# 飞书通道

## 一、能力范围

飞书 WS、`LarkSender` 出站、Get/DONE、**合并/回复/assistant 流式 CardKit**；**私聊自定义菜单**（`menu_v6` 推送事件）；**进入私聊帮助 CardKit**（`bot_p2p_chat_entered_v1`）；设置页**扫码增量开权**（`FEISHU_MENU_ADDONS`）。

**Presentation**（tool/thinking）：全通道不展示 CardKit，过程见 SDK UI 日志。

**不负责**：Daemon dispatch、凭据 UI、微信、飞书后台菜单结构配置。

## 二、设计决策与取舍

- assistant stream-text **首选 CardKit 流式**；失败 PATCH/分段（`lark-core`/`daemon`）。
- **合并卡**单卡 PATCH；按钮占位 T8。
- **静默** `MERGE_QUIET_MS` 2.5s；ready 时 processing 排队。
- **NF2**：活跃 MergeBatch 时 Presentation reply 末条 inbound。
- **eligible**：主用户 p2p + 群聊 `allowOthers`（S1.8）。
- **过程门控**（`feishu-presentation-gate.ts`）：抑制 tool/thinking CardKit；ordering 闩锁仍更新；p2p 有过程 Run 时 assistant 延迟首建。
- **菜单**：`event_key`→斜杠→`.fcmd` 复用指令路径；**无角色门控**；`buildHelpText()` 无参、全量指令 SSOT；帮助卡 **24h 节流**；菜单须在**飞书后台**配置，应用仅映射 key。

## 三、服务端规则

- 群聊须 @；F1 `buildEnqueueStatusText`（三态；排队数仅 `.qmsg`）。
- **压缩/失败 notify**：`summary-started` 发压缩提示；失败 `stop_progress`；`summary-completed` 仅 UI。
- **冷启动**：phase 空默认 `idle`；`cleanupOrphanClaimedOnColdStart` 回收 stale `.claimed`。
- **F3**：`mergeCardRegistry` 命中 → override 不入队。
- **合并卡**：预览+脚本；edit 经 `replaceSessionUnclaimedMessages`。
- **assistant 流式**：create→send→update→close；失败或含 @ → PATCH/分段；ordering defer 同前。
- **菜单/进入私聊**：`lark-core` 注册 `application.bot.menu_v6`、`im.chat.access_event.bot_p2p_chat_entered_v1`；`feishu-event-handlers` 接线 `pushCommandToQueue`/`sendHelpCard`；未知 key 文本回复。

## 四、客户端流程

入站→F1/合并卡→dispatch→Presentation→assistant 出站。菜单不经 `receive_v1`，直映射斜杠入 `.fcmd`；进入私聊 CardKit 发卡（节流跳过）。

## 六、数据

`MergeBatch`、`mergeCardRegistry`、`SessionProgressState`；`helpThrottleMap`（openId→帮助卡时间，进程内）。

## 七、非功能与可观测

## 八、推送
