# 知识地图

## 一、项目定位

Cursor Claw 是远程协作桌面应用：通过飞书/微信 7×24 接入 Cursor 等 Agent，实现私聊/群聊多会话并行、定时任务、多节点工作流与远程指令管理。Electron 负责配置/UI/Agent 启动，Daemon 负责 IM 编排与 MCP HTTP 服务。

## 二、业务域清单

- **Agent调度**：连接 Daemon 与四引擎 SDK，多会话 launch/dispatch、续接、远程指令与 Cron → [00-README](业务域/Agent调度/00-README.md)
- **消息桥接**：Daemon 外部消息入出口，飞书/微信、file-queue、Presentation 回写 → [00-README](业务域/消息桥接/00-README.md)
- **工作流**：多节点 Agent 流水线（YAML + MCP），Gateway 条件路由、isolated、驳回重跑与 resume → [00-README](业务域/工作流/00-README.md)

## 三、工程组成

与 `kb.project.json` 的 `codeRoots` 对齐：

| 根目录 | 说明 | 主要子目录 |
|--------|------|------------|
| `src/` | 应用源码（Daemon、桥接、工作流、渲染） | `bridge`、`daemon`、`workflow`、`renderer`、`shared` |
| `electron/` | Electron 主进程（Agent、会话、调度） | `agent`、`session`、`daemon`、`scheduling`、`mcp`、`config`、`workflow` |
| `resources/` | 资源模板 | `template`（skills、workflow、rule） |

工程平台知识分区：[Daemon守护进程](工程平台/Daemon守护进程/00-README.md)、[Electron桌面应用](工程平台/Electron桌面应用/00-README.md)。

## 四、外部依赖

**Agent SDK**（`package.json`）：`@cursor/sdk`、`@anthropic-ai/claude-agent-sdk`、`@openai/codex-sdk`、`@opencode-ai/sdk`。

**IM 与协议**：`@larksuiteoapi/node-sdk`（飞书）；微信 iLink（`src/bridge/wechat/`）。

**基础设施**：`@modelcontextprotocol/sdk`、`electron-store`、`electron-updater`、`node-cron`、`yaml`、`zod`。

**桌面栈**：Electron、React、Vite（`electron-vite`）。

**关键配置**：`kb.project.json`、`.cursor/hooks/feishu.env`、运行期 `agent-api-port.json`（userData，Daemon 转发 launch/dispatch）。
